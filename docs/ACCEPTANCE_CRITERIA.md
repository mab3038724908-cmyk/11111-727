# 离线改造验收标准

## 硬性门槛

以下任一失败即不接受：

1. `footprint_violation_count == 0`
2. `footprint_valid == true`
3. `path_continuous == true`
4. `coverage_complete == true`
5. `serviceable_coverage_ratio >= 0.95`
6. 每个区域的填充和沿边连续完成后才去下一区域
7. 路径不进入未知格、障碍格或用户禁区
8. `cleaner_profile` 与路径等长、数值有限、偏移不越界
9. 清扫头完整几何无碰撞
10. 所有回归测试通过

## 质量指标

与本机同一环境、同一输入比较：

- map9 非必要交叉目标：从参考约 `14` 降低至少 30%，且不得让路线长度增加超过 1%。
- map9 路线长度不得明显高于约 `466.32m`。
- 实际刷洗覆盖率不得低于基线。
- 可避免重复率不得变差。
- 规划耗时不得超过基线的 1.2 倍；若更慢，必须说明换取了什么可量化收益。
- 合成随机场景全部保持碰撞 0、连续、完整和覆盖率不低于 95%。

当前 map9 基线为 8 个区域、23 个 BCD 单元、44 条扫带、5271 个路径点、63 个硬停止点。`failure_reason` 目前也承载低价值窄区、可选沿边等诊断警告，因此不能只按该字符串是否为空判断成败；硬验收以结构化布尔量、碰撞数和覆盖率为准，但改造者必须列出并解释新增警告。

单门房间通过同一门进出、红色沿边与黄色扫带端点接触等物理必需重合，应单独分类，不能计作可避免错误。

## 可移动清扫头新增门槛

硬件参数完整后增加：

- 全部 offset 在实测行程内。
- 速度、加速度、时延和收回时间满足实测上限。
- 门口/狭窄/急转状态符合收回策略。
- 反馈未到位的地面不计入实际覆盖率。
- 故障或反馈超时能回退到收回/停止清扫的安全状态。
- 与居中基线相比，墙边覆盖增加或底盘里程/贴墙风险下降，且至少有一项可量化改善。
