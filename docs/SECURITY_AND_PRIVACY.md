# 安全与隐私边界

## 本包有意不包含

- SSH 主机、密钥和认证信息
- Jetson IP 或远程运维入口
- ROS domain/RMW 网络配置
- 导航、速度、清扫、回充 action/service 调用
- 串口、CAN、STM32 或清扫执行器驱动
- 车端启动/停止脚本

外部开发者只需要在自己的电脑上运行 Python。

## 真实地图提示

`maps/9.yaml` 和 `maps/9.png` 是真实环境布局。它们对复现基线很有用，但可能属于敏感场地图纸。转发者应确认接收范围；如果不能共享，删除 `maps/9.*` 和 `reference_outputs/map9*`，使用合成场景继续开发。

## 推荐协作方式

外部开发者返回以下之一即可：

- 修改后的完整离线包
- Git patch
- 只包含变化文件的压缩包

同时附测试 JSON、预览图和说明。无需也不应获取机器人账户。

## 上车边界

外部成果首先由项目方做源码审查和离线回归；之后才由项目方合入车端仓库。实车测试必须人在车旁、低速、分阶段执行。
